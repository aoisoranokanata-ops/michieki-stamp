# 道の駅スタンプ帳（michieki-stamp）

日本の道の駅の訪問記録とスタンプ写真を、スマホのブラウザだけで残すための個人用 PWA です。
JR・私鉄の駅スタンプや記念スタンプも、同じ仕組みで記録できます。
サーバーは持たず、記録と写真はすべて端末のブラウザ内（IndexedDB）に保存されます。

**公開 URL**：https://aoisoranokanata-ops.github.io/michieki-stamp/

## 機能

**道の駅**
- 全国 1,234 駅（国土交通省の一覧・2026年9月時点）の検索・絞り込み（都道府県／訪問済み・未訪問／スタンプ有無）
- 並び順：都道府県順・現在地から近い順（距離表示）・よみ順・最近の訪問順
- 一覧に無い道の駅の手動追加、取り込み済みの駅の編集（名称・住所・状態〔営業中／休止中／閉鎖〕・位置・登録番号など）
  - 位置は「地図をタップしてピン」「現在地」「住所から取得」「緯度経度の直接入力」のいずれかで設定
  - 保存前に重複チェック（同名、または300m以内の既存駅があれば警告）
  - 手動追加・編集した駅は、データを更新しても上書き・削除されない

**訪問記録**
- 訪問日、「訪問した」と「スタンプ取得」の別フラグ（スタンプが無かった日も記録できる）、総合評価、項目別評価、感想、メモ
- 同じ場所への複数回の訪問
- 評価項目は設定画面で追加・改名・並べ替え・非表示・削除できる（過去の記録の値は消えない）

**スタンプ写真**
- 撮影または写真の選択 → 長辺 1600px に縮小して保存（縮小のときに撮影位置などの EXIF は消える）
- 種別タグ（道の駅・駅・記念・その他）、設置場所の説明と地図のピン、メモ。記念スタンプなどは場所なしでも登録できる
- 同じ日の訪問記録に自動で紐づけ、その訪問を「スタンプ取得」にする
- スタンプ帳（グリッド表示・種別で絞り込み）

**駅・記念スポット**
- 一覧を「道の駅／駅／記念・その他」で切り替え
- 駅は駅名で検索して登録（事業者・路線・位置・都道府県が入る）。同じ駅名でも事業者・路線が違えば別の駅として記録
- 記念スポット・その他の場所も登録でき、訪問記録・スタンプ写真を同じ仕組みで残せる

**地図・統計・バックアップ**
- 地図タブ（一覧の絞り込みを反映、未訪問／訪問／スタンプで色分け、現在地）
- 統計：道の駅の達成率、都道府県別の達成率（タップでその県の一覧へ）、訪問回数、スタンプ写真の数、年ごとの訪問回数
- バックアップ ZIP の作成と復元（マージ／上書き）、最終バックアップからの日数と変更件数の警告

**オフライン**
- ホーム画面に追加すると、通信できない場所でも起動して記録・写真の保存ができます（地図の画像だけは通信が必要）。
- 新しい版を公開すると、アプリの下に「新しい版があります」と出ます。「更新する」で切り替わります。

## 使い方

### ホーム画面への追加（おすすめ）

**iPhone（Safari）**
1. Safari で公開 URL を開く
2. 画面下の共有ボタン（□に↑）をタップ
3. 「ホーム画面に追加」→「追加」

**Android（Chrome）**
1. Chrome で公開 URL を開く
2. メニュー（︙）から「ホーム画面に追加」または「アプリをインストール」
   （アプリの「設定」に「ホーム画面に追加（インストール）」ボタンが出ることもあります）

ホーム画面から起動すると、iPhone でもブラウザのデータが消されにくくなります。

### 記録のしかた
1. 「道の駅」タブで駅を探す（現在地から近い順が便利）
2. 駅の画面で「＋ 訪問を記録」、スタンプは「撮る・選ぶ」
3. 位置情報の利用を聞かれたら許可する（「近い順」やピンの設定に使います。端末の外には送りません）

## バックアップの注意

- 記録と写真は、その端末のブラウザの中だけに保存されます。サーバーには送られず、ほかの端末とも自動では同期しません。
- **iPhone の Safari は、しばらく使わないサイトのデータを消すことがあります。** ホーム画面に追加して使い、
  定期的に「設定 → バックアップを作成」で ZIP を保存してください（「ファイル」アプリの iCloud Drive など）。
  14日以上たって記録に変更があると、一覧に警告が出ます。
- 機種変更や別の端末へ移すときは、ZIP を「設定 → バックアップから復元」で読み込みます。
  - **マージ**：今の記録に足す（同じ記録は更新日時の新しい方を残す。削除したことは引き継がれない）
  - **上書き**：今の記録・写真・手動追加した場所を消して、ZIP の内容に置き換える
- バックアップ ZIP には写真と個人の記録が入っています。他の人と共有しないでください（このリポジトリにも入れません）。
- ZIP の中身：`manifest.json`（形式・件数）、`data.json`（場所・訪問・スタンプ・評価項目）、`photos/`・`thumbs/`（JPEG）

## データの出典と利用条件

詳細は [data/DATA_LICENSE.md](data/DATA_LICENSE.md) を参照してください。

| データ | 出典 | 利用条件 |
|---|---|---|
| 道の駅の駅名・よみ・所在地・登録回・登録年月・公式URL | [国土交通省「道の駅」一覧](https://www.mlit.go.jp/road/Michi-no-Eki/list.html) を加工して作成 | 公共データ利用規約 第1.0版（CC BY 4.0 互換） |
| 道の駅の位置（1,128 駅） | © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors | ODbL 1.0 |
| 道の駅の位置（残り 106 駅） | 同梱しない。アプリ内で利用者が各自設定 | — |
| 駅名の入力補助（`data/stations.json`） | 「[国土数値情報（鉄道データ）](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2024.html)」（国土交通省）を加工して作成 | CC BY 4.0 |
| 地図 | [国土地理院（地理院タイル・標準地図）](https://maps.gsi.go.jp/development/ichiran.html)。地図の右下に出典を表示 | 国土地理院コンテンツ利用規約 |

- `data/michinoeki.json` は ODbL 1.0 で提供します（OpenStreetMap 由来の位置を含むため）。所在地は市町村までです。
- 地図は表示のつど読み込みます。オフライン用の一括ダウンロードはしません。
- 「住所から座標を取得」と、駅を選んだときの都道府県の判定には、国土地理院の住所検索（`msearch.gsi.go.jp`）と
  逆ジオコーダ（`mreversegeocoder.gsi.go.jp`）を使います。操作1回につき1回だけ、入力した住所または選んだ駅の座標を送ります。
  公式な利用規約の掲載が無く試験運用扱いのため、取得結果は同梱データに含めず、端末内にだけ保存します。
  使えないときは、地図のピン・現在地・緯度経度の直接入力で設定できます。
- 現在地は「近い順」やピンの設定の操作時だけ取得し、保存も外部送信もしません。
- このアプリおよび加工データは、国土交通省・国土地理院が作成したものではありません。

## 開発

ビルド工程はありません。`index.html`（アプリ本体）・`sw.js`（Service Worker）・`manifest.json` と、
`data/`・`vendor/`・`icons/` をそのまま配信します。

```
python -m http.server 8672           # ローカル確認（http://localhost:8672/）
python tools/convert.py --refresh    # 道の駅データの作り直し（国交省一覧＋OSM）
python tools/convert_stations.py     # 駅データの作り直し（国土数値情報 鉄道）
python tools/make_icons.py           # アイコンの作り直し（Pillow が必要）
```

- 版を上げるときは `index.html` の `APP_VERSION` と `sw.js` の `VERSION` を必ずそろえる。
- GitHub Pages は他のアプリと同じオリジンを共有するため、IndexedDB 名・localStorage のキー・キャッシュ名には
  `michieki-stamp` を付け、Service Worker は自分のキャッシュだけを消す。

## 開発フェーズ

1. MVP：データ取り込み・一覧・検索・訪問記録 ✓
2. スタンプ写真（撮影・縮小・保存・スタンプ帳） ✓
3. 位置機能（近い順・地図・設置場所のピン） ✓
4. 駅スタンプ・記念スタンプ ✓
5. バックアップ（ZIP 書き出し・読み込み） ✓
6. 仕上げ（PWA 化・統計・README） ✓

端末間の自動同期は対象外です（ZIP の書き出し・読み込みで代替）。
