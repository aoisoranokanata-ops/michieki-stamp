# 道の駅スタンプ帳（michieki-stamp）

日本の道の駅の訪問記録とスタンプ写真を、スマホのブラウザだけで残すための個人用 PWA です。
サーバーは持たず、記録はすべて端末のブラウザ内（IndexedDB）に保存されます。

> 開発中（フェーズ2まで完了：一覧・検索・訪問記録・スタンプ写真）。完成までの機能は下記「開発フェーズ」を参照。

## 機能（現時点）

- 全国の道の駅一覧（国交省一覧ベース）の検索・絞り込み（都道府県／訪問済み・未訪問／スタンプ有無）
- 訪問記録の追加・編集・削除（訪問日・訪問／スタンプ取得の別フラグ・総合評価・項目別評価・感想・メモ）
- 同じ道の駅への複数回訪問
- 評価項目は設定画面で追加・改名・並べ替え・非表示・削除できる（過去の記録の値は key で保持され、消えない）
- 道の駅の手動追加と、取り込み済みの駅の編集（名称・住所・状態〔営業中/休止中/閉鎖〕・位置・登録番号など）
  - 位置は「住所から取得」または緯度経度の直接入力（地図ピン・現在地はフェーズ3で追加）
  - 保存前に重複チェック（同名、または300m以内の既存駅があれば警告）
  - 手動追加・編集した駅は、データを更新しても上書き・削除されない
- スタンプ写真の撮影／選択 → 長辺1600pxに縮小して端末内に保存（縮小時に EXIF〔撮影位置など〕は除去）
  - 種別タグ（道の駅・駅・記念・その他）、設置場所の説明、メモ。記念スタンプなどは場所なしでも登録可
  - 訪問記録と紐づけ（同じ日の訪問に自動で紐づけ、その訪問を「スタンプ取得」にする）
- スタンプ帳（グリッド表示・種別で絞り込み）

## データの出典と利用条件

同梱の `data/michinoeki.json` は **ODbL 1.0** で提供します（詳細は [data/DATA_LICENSE.md](data/DATA_LICENSE.md)）。

| データ | 出典 | 利用条件 |
|---|---|---|
| 駅名・よみ・所在地・登録回・登録年月・公式URL | [国土交通省「道の駅」一覧](https://www.mlit.go.jp/road/Michi-no-Eki/list.html) を加工して作成 | 公共データ利用規約 第1.0版（CC BY 4.0 互換） |
| 位置（1,128 駅） | © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors | ODbL 1.0 |
| 位置（残り 106 駅） | 同梱しない。アプリ内で利用者が各自設定 | — |

- 所在地は市町村までです。
- 「住所から座標を取得」は国土地理院の住所検索（`msearch.gsi.go.jp`）を使います。ボタン1回につき1リクエストで、
  自動の一括取得はしません。公式な利用規約の掲載が無く試験運用扱いのため、取得結果は同梱データに含めていません。
  使えない場合は緯度経度を直接入力できます（地図ピン・現在地による設定はフェーズ3で追加）。
- このアプリおよび加工データは、国土交通省・国土地理院が作成したものではありません。
- `data/michinoeki.json` は `python tools/convert.py --refresh` で作り直せます。
