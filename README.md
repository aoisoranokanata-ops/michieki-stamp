# 道の駅スタンプ帳（michieki-stamp）

日本の道の駅の訪問記録とスタンプ写真を、スマホのブラウザだけで残すための個人用 PWA です。
サーバーは持たず、記録はすべて端末のブラウザ内（IndexedDB）に保存されます。

> 開発中（フェーズ1：一覧・検索・訪問記録）。完成までの機能は下記「開発フェーズ」を参照。

## 機能（現時点）

- 全国の道の駅一覧（国交省一覧ベース）の検索・絞り込み（都道府県／訪問済み・未訪問／スタンプ有無）
- 訪問記録の追加・編集・削除（訪問日・訪問／スタンプ取得の別フラグ・総合評価・項目別評価・感想・メモ）
- 同じ道の駅への複数回訪問
- 一覧に無い道の駅の手動追加

## 開発フェーズ

1. MVP：データ取り込み・一覧・検索・訪問記録 ← いまここ
2. スタンプ写真（撮影・縮小・保存・スタンプ帳）
3. 位置機能（近い順・地図・設置場所のピン）
4. 駅スタンプ・記念スタンプ
5. バックアップ（ZIP 書き出し・読み込み）
6. 仕上げ（PWA 化・統計・README）

## データの出典と利用条件

| データ | 出典 | 利用条件 |
|---|---|---|
| 道の駅の駅名・よみ・所在地・登録回 | [国土交通省「道の駅」一覧](https://www.mlit.go.jp/road/Michi-no-Eki/list.html) を加工して作成 | 国土交通省ウェブサイト利用規約（公共データ利用規約 第1.0版、CC BY 4.0 互換） |
| 道の駅の位置（主） | © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors | ODbL 1.0 |
| 道の駅の位置（OSM に無い駅） | [国土地理院 住所検索](https://msearch.gsi.go.jp/) による市町村の代表点 | 国土地理院コンテンツ利用規約 |

- 所在地は市町村までです。OSM で見つからなかった駅の位置は市町村の代表点（概略）で、実際の場所とずれます。
- このアプリおよび加工データは、国土交通省・国土地理院が作成したものではありません。
- `data/michinoeki.json` は `tools/convert.py` で生成しています（`python tools/convert.py --refresh` で取り直し）。
  このファイルの位置情報部分は ODbL に従います。
